# Windows IT Support & Troubleshooting Home Lab

## Project Overview

A hands-on IT Support home lab designed to develop practical skills in Windows administration, troubleshooting, networking, user account management, and technical documentation.

The lab uses a Windows 11 Pro ARM virtual machine running through UTM on an Apple Silicon MacBook.

I complete simulated Help Desk scenarios, investigate technical issues using Windows administrative tools, and document the troubleshooting process through structured support tickets.

## Lab Environment

- **Operating System:** Windows 11 Pro ARM
- **Virtualization:** UTM
- **Host Platform:** Apple Silicon macOS
- **Tools:** Command Prompt, Task Manager, Computer Management, Local Users and Groups, Microsoft Edge
- **Networking Utilities:** ipconfig, ping, nslookup, tracert
